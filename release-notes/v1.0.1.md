# LAN Browser Relay v1.0.1

## Fixes and hardening

- Fix Kotlin compilation errors in server status handling and network-address selection.
- Bind navigation messages from proxied pages to the active browser session and reject synthetic link clicks.
- Remove the global logs endpoint so one browser session cannot inspect other sessions' transfer filenames and activity.
- Correct global versus per-session download concurrency coverage.
- Fix SDK manager discovery in the release workflow.
- Require persistent release signing credentials, validate version metadata, and verify the built APK before publishing.

## Validation

The merged security PR passed the hostile-page browser integration test, Android debug build, unit tests, lint, APK integrity/signature verification, and version-metadata checks in GitHub Actions.
